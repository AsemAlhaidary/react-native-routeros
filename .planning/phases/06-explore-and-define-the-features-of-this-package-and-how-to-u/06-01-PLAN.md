## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Docs → reader | Example code and prose must not leak credentials or misrepresent the API's security behavior |
| Library → RouterOS device | Plain TCP (port 8728) is cleartext; TLS (port 8729) is the encrypted path (documented, not changed) |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-06-01 | Information Disclosure | examples/basic-usage.ts, docs/API.md | high | mitigate | Examples use placeholder credentials ('admin'/'password') with an explicit comment to use env vars / secure key store; no real secrets in any artifact |
| T-06-02 | Spoofing (MITM) | docs/API.md TLS section | high | mitigate | Document that `tls: { ca }` pins the self-signed RouterOS CA (TlsRnOptions.ca accepts PEM); note plain TCP 8728 is cleartext and TLS 8729 should be used beyond trusted LANs |
| T-06-03 | Information Disclosure | docs/API.md login description | medium | mitigate | Document that connect() performs MD5 challenge-response login and that credentials traverse the socket, without exposing the challenge buffer internals beyond what src/RouterOSAPI.ts already does |
