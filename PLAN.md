There is an awesome node.js library for managing communication with the mikrotik routeros api called node-routeros. It works well on web and similar projects, but it doesn't work well with react-native. Therefore, I decided to create this repo called react-native-routeros, and it will be built completely on the foundation of the node-routeros library, as the original node-routeros library is present in the project folder, and the new library codes will be built completely on the basis of the old one, with the same style of structure, codes, and method of use, with the exception of modifying the necessary parts to suit React Native projects. The new library must be completely independent and must not depend on the node-routeros library to work. The new library will be built using typescript. Then I want to document it clearly and upload it to my GitHub account and also to the npm platform so that any other developer can install it and benefit from it.
